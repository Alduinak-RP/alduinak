# Skyrim Interface Elements

UI artwork in this folder is from the **Skyrim Interface Elements** resource pack
by **SanneARBY**:

https://www.nexusmods.com/skyrimspecialedition/mods/82169

Imported categories: Bars, Boxes, Menu Icons, Fonts, Keys (PC glyphs) and
Loading icons. The pack's large animated GIFs (HUD Elements, Title) and the
Map Markers set are not imported; grab them from the Nexus page if needed.

Keep this notice with the assets and credit SanneARBY in anything that ships
them.
