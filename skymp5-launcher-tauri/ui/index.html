Server Hotkeys

Install mods first.

Click a key, then press the new key or mouse button (middle, Mouse 4, Mouse 5). Esc or a left/right click cancels, Backspace unbinds any key except Interact / Menus. Enter always focuses chat. Interact / Menus (default X) opens the housing menu on a door or container, the interaction menu on a player, and your Personal Menu (Admin, Faction, Skills, Debug) anywhere else. The Activate key from Game Hotkeys still opens the interaction menu on players. Emote Wheel (default B) opens the emote wheel, and pressing it again closes the wheel. Changes apply the next time you start the game.

Interact / Menus shares a key with Activate. Activate wins, so the housing menu and Personal Menu will not open until the keys differ.

Game Hotkeys

Install mods first.

Written to the game's controlmap; a mouse button replaces the key. Changes apply the next time you start the game.

Discord

Shows "Playing Alduinak" and the player count on your Discord profile while the game runs and this launcher stays open. Needs the Discord app and its "Share your detected activities with others" setting.

With Portable Installation and MO2 on, PLAY deletes any file the launcher does not install from the portable game copy, ENB and ReShade included. Your original Skyrim is never touched.
