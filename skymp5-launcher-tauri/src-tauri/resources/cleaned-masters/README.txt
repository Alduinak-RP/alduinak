The Simple Cleaned Masters xdelta patches (*.vcdiff) the launcher applies to clean the Skyrim masters.
The server manager's Build launcher copies them here from build/client-files/cleaned-masters for the
website installer and removes them again before it re-bundles the nginx installer; they are not tracked
in git. A patch missing here, or failing its checksum, is downloaded from the server instead. Credit to
the Simple Cleaned Masters author for the patches.
