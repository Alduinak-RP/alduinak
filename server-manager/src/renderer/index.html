Select a player, or General Stats.

    Game Server

    Bundles the TS server into build/dist/server and rebuilds gamemode.js from gamemode_extensions/.

    Launcher

    Save sets the version of the next build only. Build launcher writes build/launcher/AlduinakLauncher.exe; upload it, then Update Version tells every launcher to update.

    Client

    Build client rebuilds the UI and skymp5-client.js into build/dist/client for the Nexus client files. Update modlist builds the manifest from MO2, syncs the server's load order and Data folder and fixes the database for moved or removed plugins; then Update Version, once the Nexus files are live.
