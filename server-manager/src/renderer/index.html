Select a player, or General Stats.

    Server

    Builds land in build/dist/testserver: the TS bundle into dist_back, gamemode.js from gamemode_extensions/. The Test Server hot-reloads gamemode.js; restart it for dist_back or scam_native.node. Test version Save writes skymp5-server/package.json and the test server version.

    Client

    Build client rebuilds the UI and skymp5-client.js into build/dist/testclient; package its Data folder as the Alduinak Client Files mod, upload it to Nexus and install it into MO2. The button then reads Update Modlist (manifest from MO2, test server load order, Data folder and database), then Update Version, which publishes the test client version. Test version Save writes skymp5-client/package.json only. Test server must be stopped

    Migrate

    Only way to the Main Server, which must be stopped. Migrate server copies dist_back, scam_native.node, gamemode and the server data files (never the world, settings or player state); it then reads Migrate settings, which merges new test settings into the live server-settings.json without touching its name, ports, players, database, access or Discord keys. Migrate client installs the test manifest, modlist and extras live, syncs the live load order, Data folder and database and mirrors build/dist/testclient onto build/dist/client. Old files go to build/dist/backup. The Live and Test rows publish the server and client versions of that side in versions.json (Save writes the filled fields only); Copy test build fills both from the skymp5-server and skymp5-client packages. Versions may carry a build, e.g. 1.2.3-b4 or 1.2.3+4. Main server must be stopped

    Launcher

    Version Save sets the version of the next build only. Build launcher writes build/launcher-website/AlduinakLauncher.exe (with the cleaned-master patches) and build/launcher/AlduinakLauncher.exe (without them, served by nginx for old launchers); zip the website one and upload the zip to the website so the Download URL serves it (https only; the launcher follows the website's redirect and unpacks the zip), then Update Version tells every launcher to update. Downloads then come from the website, not this server.
