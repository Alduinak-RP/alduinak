    Client
    
          
    
            
            
    
              
              
            
    
          
    
          Rebuilds the front-end UI and skymp5-client.js into build/dist/client, then zips the client files into skymp-client.zip for the launcher. Drop the CI dist (.dll) into build/dist/client first (or tick CMake below); set Version first.
