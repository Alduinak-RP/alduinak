Select a player, or General Stats.

    Server

    Builds land in build/dist/testserver: the TS bundle into dist_back, gamemode.js from gamemode_extensions/. The Test Server hot-reloads gamemode.js; restart it for dist_back or scam_native.node. Test version Save writes skymp5-server/package.json and the test server version.

    Client

    Build client rebuilds the UI and skymp5-client.js into build/dist/testclient; package its Data folder as the Alduinak Client Files mod, upload it to Nexus and install it into MO2. The button then reads Update Modlist (manifest from MO2, test server load order, Data folder and database), then Update Version, which publishes the test client version. Test version Save writes skymp5-client/package.json only. Test server must be stopped

    Migrate

    Only way to the Main Server, which must be stopped. Migrate server copies dist_back, scam_native.node, gamemode and the server data files (never the world, settings or player state); it then reads Migrate settings, which merges new test settings into the live server-settings.json without touching its name, ports, players, database, access or Discord keys. Migrate client installs the test manifest, modlist and extras live, syncs the live load order, Data folder and database and mirrors build/dist/testclient onto build/dist/client. Old files go to build/dist/backup. Live version Save writes client and server into versions.json; Copy test build fills the field from the test build. Main server must be stopped

    Launcher

    Save sets the version of the next build only. Build launcher writes build/launcher/AlduinakLauncher.exe; upload it, then Update Version tells every launcher to update.
