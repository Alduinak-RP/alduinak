# Emote wheel and prop emotes

The emote wheel (default `B`, setting `emoteWheelKeyCode`, rebindable in the chat settings' Controls tab) plays
vanilla idles on the local player; other players see them through the regular animation sync. The key toggles
the wheel; with "hold the emote wheel key" ticked in Controls it is held open instead, and releasing it plays
the emote under the cursor (or only closes the wheel when nothing is hovered). Hold mode works with keyboard
keys only, since the focused wheel forwards key releases and not mouse buttons. Movement keys (`W A S D`,
`Space`) end an emote, and so does drawing a weapon or spell. A draw leaves an idle by itself, so no idle exit event is sent while the hands
are drawn; an offset overlay such as Crossed Arms is not an idle, so a draw still sends its `OffsetStop`.

- Client: `skymp5-client/src/services/services/emoteService.ts` (the `GROUPS` catalog, playing, exiting, the
  prop gate).
- Front: `skymp5-front/src/features/emoteWheel/` (the radial widget, id 24). The preview gif animates only
  while the cursor is over an emote slice; otherwise the panel shows its first frame, so an idle wheel costs no
  frame time.
- Server: nothing. Animation packets are relayed unchecked (`ActionListener::OnUpdateAnimation`).

## Emotes that need an item

An instrument, horn or broom emote plays only while the character carries the item. The check reads the
client's copy of the server inventory, so a dropped, traded or stored item counts as gone at once.

| Emote | Needs one of |
|---|---|
| Play Lute | Lute (`Skyrim.esm` 0DABAB), Lute (`City of Dawnstar.esp` 0A8A0E) |
| Play Flute | Flute (0DABA7), Flute (105177), The Dancer's Flute (105109) |
| Play Drum | Drum (0DABA9) |
| Sweeping | Broom (06717F) |
| Horn (Imper.) | Imperial War Horn (0200BA) |
| Horn (Stormcl.) | Nord War Horn (0200B6), Torygg's War Horn (0E77BB), Vrage's Horn (`WindhelmSSE.esp` 1252BE) |

Drink, Eating, Read Note, Read Book and Use Hoe stay free. Quest names such as Finn's Lute or Pantea's Flute
are aliases on the base records, so those count too.

- **Wheel:** a locked slice is greyed out. Hovering still previews it, with the preview in greyscale under
  "Requires a lute". Clicking it keeps the wheel open and the centre reads "NEEDS A LUTE". The locked state
  is re-pushed whenever the inventory changes while the wheel is open.
- **Play:** a play request for a locked emote (another service, or a stale widget) is refused with "You need
  a lute for this emote." before the weapon is sheathed.
- **Losing the item mid-emote:** the emote stops through its normal exit chain with "You no longer carry a
  lute.", but only while the prop is really in hand (`bAnimObjectLoaded`). An idle already ended by combat,
  furniture or mounting is only forgotten, so no exit event reaches a player who is doing something else.
- **Limits:** the check is client-side only. A modified client can still play the idle, which is cosmetic. One
  instrument can be handed around by trade, since playing never uses it up.

Items are listed as `hex:Plugin` descs in `PROPS` and resolved with `formIdFromDesc`
(`skymp5-client/src/view/worldViewMisc.ts`) on an update, where natives are allowed. An item whose plugin is
missing simply never counts.

## Where the items come from

Placed instruments and brooms are world decor (`MISC` is in `forbiddenReloot`) and NPCs are off, so the
Alduinak plugin adds common recipes: any character makes them at Novice, whatever their profession, and they
earn no mastery hours (see `docs_roleplay_mastery.md`).

| Item | Bench | Materials |
|---|---|---|
| Lute | Woodcrafting Bench | 2 Firewood, 2 Leather Strips |
| Flute | Woodcrafting Bench | 1 Firewood |
| Drum | Woodcrafting Bench | 2 Firewood, 1 Leather |
| Broom | Woodcrafting Bench | 1 Firewood, 1 Straw |
| Imperial War Horn | forge | 1 Mammoth Tusk, 1 Iron Ingot, 1 Leather Strips |
| Nord War Horn | forge | 1 Mammoth Tusk, 1 Iron Ingot, 1 Leather Strips |

The broom takes Hearthfire Straw (`BYOHMaterialStraw`, HearthFires.esm), the owner's choice over Wheat; the
Haybales passive job pays Straw (`docs_roleplay_jobs.md`). The recipes live in `kilnRecipes` of
`misc/proficiency-patcher/spec.json`; staff can still hand items out with the admin item spawn.
